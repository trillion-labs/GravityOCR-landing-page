인터넷이 필요한가요?+

첫 모델 설치에는 인터넷이 필요합니다. 설치 후 문서 인식은 오프라인으로 실행합니다.

어떤 파일을 열 수 있나요?+

PDF, PNG, JPEG, HEIC 파일을 지원합니다.

어떤 모델을 사용하나요?+

Trillion Labs가 공개한 GravityOCR-KO 모델을 사용합니다. GravityOCR를 한국어 문서로 더 학습한 모델입니다. 가중치는 Hugging Face에서, 기술 보고서는 arXiv에서 볼 수 있습니다.
