Gravity 앱

Gravity는 선택한 이미지와 PDF를 사용자의 Mac에서 처리합니다. 문서 내용과 OCR 결과를 Trillion Labs 서버로 업로드하지 않으며, 앱에 분석 SDK나 광고 SDK를 포함하지 않습니다.

앱은 선택한 문서, 사용자가 저장한 Markdown 결과, 앱 설정을 처리합니다. 설정은 macOS의 앱 기본 설정 저장소에 보관됩니다. OCR 중 생성한 임시 PDF 페이지 이미지는 처리가 끝나거나 취소되면 삭제하도록 설계되어 있습니다.

Gravity 웹사이트

이 웹사이트에는 회원가입, 문서 업로드, 광고 또는 자체 분석 스크립트가 없습니다. 다만 웹 호스팅과 네트워크 제공자는 보안과 전송을 위해 IP 주소, 요청 시각, 브라우저 정보 같은 일반 접속 기록을 처리할 수 있습니다.

외부 연결

첫 실행에서 모델 파일을 받기 위해 Hugging Face에 연결하며, 이때 문서 내용은 전송하지 않습니다. 웹사이트의 설치 파일 다운로드와 외부 링크를 열 때는 해당 서비스의 개인정보 처리방침이 적용될 수 있습니다. 모델 설치 후 문서 인식 기능은 오프라인 실행을 기본으로 합니다.
