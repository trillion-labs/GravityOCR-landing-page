A few details

Will Gravity be free?+

Yes. Gravity is planned as a free download.

Does it need the internet?+

Internet is required for initial model installation. After that, document recognition runs offline.

How much space does it use, and how do I remove it?+

The app is about 420 MB, and the recognition model it downloads on first run is about 2.2 GB. Moving Gravity to the Trash leaves the model behind. From version 0.3.2, choose Gravity ▸ Storage… to see what it keeps and to remove everything. In earlier versions, also delete ~/Library/Application Support/Gravity, ~/Library/Caches/ai.trillionlabs.gravity and ~/Library/Logs/Gravity.

Which files can I open?+

Gravity supports PDF, PNG, JPEG, and HEIC files.

Which model does it use?+

GravityOCR-KO, a version of GravityOCR further trained on Korean documents, both released by Trillion Labs. The weights are on Hugging Face and the technical report is on arXiv.
