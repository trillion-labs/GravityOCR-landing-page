A few details

Will Gravity be free?+

Yes. Gravity is planned as a free download.

Does it need the internet?+

Internet is required for initial model installation. After that, document recognition runs offline.

Which files can I open?+

Gravity supports PDF, PNG, JPEG, and HEIC files.

Is this the final design?+

The main image is a product design preview. The table and equation examples below are actual extraction results. The final interface may change.
