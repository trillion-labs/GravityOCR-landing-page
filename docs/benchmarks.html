1.18초의 측정 범위

2026년 9월 11일, M3 Pro 18GB에서 슬라이드 1장(12개 영역)을 처리한 warm 프로파일입니다. 기록값은 1,177.58ms이며, 모델 다운로드·최초 로딩 시간이나 최종 앱 화면 표시까지의 시간을 뜻하지 않습니다. 5회 평균이 아닌 단일 전체 실행 기록입니다.

PP-DocLayoutV3 FP32 + MLX Q6/K16 경로입니다. 각 단계 합계와 전체 시간 차이 약 10ms는 기타 시간으로 포함했습니다. 전원·외부 부하 조건은 이 프로파일에 명시돼 있지 않습니다.

3.24배의 비교 기준

완성된 멀티모달 prefix cache 이후 EOS까지 59개 출력 토큰의 디코딩 구간입니다. MLX BF16 AR 877.12ms / MLX Q6 K16 self-spec 270.87ms의 두 프로세스 중앙값 비율 3.2382를 반올림했습니다. 각 프로세스는 방식별 워밍업 1회, 측정 5회를 수행했습니다.

레이아웃·이미지 로딩/리사이즈·비전 인코더·멀티모달 prefill·tokenizer decode는 제외합니다. 배터리 상태와 Chrome 동시 부하가 있던 진단 실험이며 전원 연결·무부하 재측정이 필요합니다. 왼쪽 1.18초 프로파일과는 별도 실험입니다.
